# Reviewer attack matrix

| Attack | Diagnostic/control | Consequence / required response |
|---|---|---|
| Pseudoreplication: calls counted as animals | Report animal/litter N, grouped holdouts and hierarchical uncertainty | Recompute at proper unit; narrow inferential scope |
| Animal or litter leakage | Synthetic invariant tests now; full manifest checks after M0 | Block affected comparison |
| Duplicate recordings across splits | SHA-256 file audit now; future decoded-PCM duplicate audit | Preserve copies; group/review before splitting |
| Age signal is acquisition/background | Background-only, date/session, gain/noise-only probes | Reassess identifiability and claim scope |
| Metadata identities were guessed | Source-located assertion ledger, conflict report, reviewed mapping status | Quarantine affected claim; retain unresolved alternatives |
| Test data shaped preprocessing or SSL | Fit-ID ledger for all learned transforms; locked split digest | Invalidate confirmatory label or use fresh holdout |
| Missingness/exclusions favor result | Full denominators, outcome-awareness log, sensitivity analyses | Qualify bias; retain negative findings |
| Detector errors vary by age/domain | Blinded stratified annotation and detector sensitivity checks | Propagate error; revise feature validity |
| Model complexity hides weak baseline | Classical/linear/tree/CNN benchmark ladder with identical splits | No complexity claim without measured incremental value |
| Nuisance suppression removes biology | Domain/biology correlation audit and branch/probe ablations | Do not claim invariant biology from adversarial loss alone |
| Latent dimensions falsely named biology | Identifiability limits, perturbation stability and concept tests | Use descriptive latent labels until independently validated |
| Attractive UMAP is the evidence | Show full-space evaluation, uncertainty and projection sensitivity | Relabel as exploratory |
| External dataset is a different question | Cohort/age/protocol compatibility matrix | State transfer claim rather than developmental validation |
| Hidden negative results | Complete run/seed registry including failures | Correct selective reporting |
| Model is called novel prematurely | Dated systematic nearest-method literature comparison | Keep NASS internal name, no novelty assertion |
