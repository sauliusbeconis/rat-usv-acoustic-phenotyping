# Dataset Atlas

Run `usv dataset-atlas` with an inventory and optional WAV audit. Private technical JSON and Markdown are written to the configured output root. Biological counts stay null until reviewed registries exist; the current command does not calculate animal/day/sex/weight coverage. Future M0 atlas must add confirmed identities, unresolved/conflicting links, days, missing sessions, weights/sex with units, litter/dam coverage and exclusion denominators. Never count filename stems as animals.
